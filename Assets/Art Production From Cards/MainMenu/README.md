# Soul Of Dead War main-menu art

- `MainMenu-Background-1080x1920.png`: portrait background, no baked text or buttons. All six allied characters appear around a central menu path, with the requested crimson relic battle atmosphere.
- `Soul-Of-Dead-War-Logo.png`: separate 1774 x 887 RGBA logo, exact title SOUL OF DEAD WAR, transparent outside the artwork. Gold lettering, crimson cracks and a stone crest; diamond ornaments removed.
- `Sources/MainMenu-Background-Original.png`: original 941 x 1672 generated background, retained for later edits. The 1080 x 1920 delivery is a proportionally fitted Lanczos resize with negligible edge crop.

The three combat illustrations in the parent folder were the visual references; together they contain the six supplied allies. Both assets were generated using the built-in image generator. Exact prompts and the logo refinement are in `Generation-Prompts.json`.

Use the background and logo as separate Unity Images, with editable menu buttons above them. These files are prepared as artwork for review; they have not replaced the current main-menu scene. App Store submission still depends on the built game's release checks.
